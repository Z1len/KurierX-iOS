# KurierX iOS v6

Полная замена предыдущего iOS-проекта. Перед загрузкой удалите старые Swift-файлы из `KurierX-iOS` и загрузите содержимое этой папки в корень репозитория.

Основные изменения v6: Developer PIN + Face ID, выбор любого дня календаря и русский месяц, OCR календаря с привязкой колечек к разным датам, просмотр импортированных колечек по дню, ручное добавление клиентов после OCR, редактируемые смены/цели, причина досрочного закрытия, открываемые карточки трасс, автоматический расчёт итогов трассы, OCR-точки входа для бонусов/штрафов, переработанный дизель/авторасход.
